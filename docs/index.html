Quick Start

Three commands. Zero config.

Clone the repo, install one dependency, and you're scanning. API key is free — no credit card, no trial period.

$ git clone https://github.com/BMNTR/TriageTalon.git
$ cd TriageTalon
$ pip install -r requirements.txt

# Start scanning
$ python recon.py -d target.com -k YOUR_KEY
